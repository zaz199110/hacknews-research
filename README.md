# HackNews Research

> **基于用户反馈持续优化的 HackerNews 智能新闻筛选工具**

从 HackerNews 采集自定义关键词的相关新闻，自动翻译为中文并生成 AI 摘要，通过你的反馈学习偏好，让推荐越来越精准。

---

## 1 产品定位

**HackNews Research** 是一款本地运行的 Web 工具，面向关注 AI / LLM / Fintech 领域的开发者和研究者。

核心价值：**不只是搜索，而是"越用越懂你"的新闻助手。**

- 从 HackerNews 拉取相关文章
- 自动翻译为中文 + LLM 生成摘要
- 通过 👍👎 快捷反馈 + 文字反馈，持续积累你的偏好
- 关键词池根据反馈动态调整权重，下一次搜索自动优化排序

**你的每一次反馈，都会让下一次结果更好。**

---

## 2 产品亮点

### 2.1 越用越懂你的智能排序

传统新闻工具只有搜索，没有学习。HackNews Research 通过反馈闭环，让你的搜索结果随使用时间推移越来越精准。

**排序公式**

```
最终得分 = HN 点赞数 × 0.6 + 偏好池打分 × 0.4
```

- **HN 热度**（60%）：反映社区共识
- **偏好池打分**（40%）：反映你的个人兴趣

首次搜索以社区热度为主，随着反馈积累，个人偏好逐渐生效。

```
第 1 次搜索  → 全靠 HN 热度排序（冷启动）
第 10 次搜索 → 开始感知你的偏好
第 50 次搜索 → 排序高度个性化
```

### 2.2 大模型驱动的关键词智能

#### 2.2.1 自动提取

从新闻标题和摘要中自动提取技术关键词（模型名称、技术领域、应用场景、公司机构）。

#### 2.2.2 语义归一化

LLM 识别语义相似的关键词并合并，避免得分分散：

| 原始词 | 归一化后 |
|--------|----------|
| LLMs | LLM |
| Language Models | LLM |
| GPT-4o | GPT-4o |
| Maths | Math |

归一化结果缓存到数据库，避免重复调用 LLM，节省成本。

#### 2.2.3 智能反馈分析

文字反馈由 LLM 理解语义，自动提取关键词并判断正负面，独立于快捷反馈更新关键词池。

### 2.3 反馈学习系统

#### 2.3.1 快捷反馈

对每条新闻点 👍 或 👎，即时更新对应关键词得分。

#### 2.3.2 文字反馈

输入自然语言描述偏好，LLM 自动提取关键词并调整权重。

#### 2.3.3 关键词池

| 关键词 | 得分 | 来源 |
|--------|------|------|
| Agent | +12 | 用户多次点赞 |
| RAG | +8 | 用户文字反馈希望提高 |
| 微调 | -3 | 用户点踩 |

#### 2.3.4 衰减机制

关键词得分随时间自然衰减，防止早期偏好永久锁定排序：

```
当前得分 = 原始得分 × 0.95 ^ (天数 / 7)
```

| 时间 | 原始得分 | 衰减后 |
|------|----------|--------|
| 今天 | +10 | +10.0 |
| 7 天前 | +10 | +9.5 |
| 30 天前 | +10 | +8.1 |
| 90 天前 | +10 | +5.0 |

### 2.4 搜索与采集

- 自定义关键词搜索（LLM、Fintech、Agent、RAG... 任意组合）
- 支持 AND / OR 关键词关系
- 按日期范围筛选
- 每次搜索保存为独立会话，支持历史查看

### 2.5 自动翻译与摘要

- 搜索结果自动翻译为中文标题
- 抓取文章全文，LLM 生成中文摘要
- 支持配置任意 OpenAI 兼容的 LLM 服务（DeepSeek / 通义千问 / 智谱 / Ollama 本地模型）

### 2.6 Markdown 导出

- 勾选感兴趣的新闻
- 一键导出为格式化的 Markdown 日报
- 包含标题、摘要、来源链接、发布时间

### 2.7 关键词管理

- 查看所有关键词及其当前得分
- 支持编辑得分、删除关键词
- 反馈统计：总反馈数、👍 数、👎 数

### 2.8 轻量本地部署

- SQLite 本地存储，无需数据库服务
- 纯 Web 界面，浏览器直接访问
- 支持 Windows / macOS / Linux

## 4 快速开始

### 4.1 环境要求

- Python 3.10+
- pip

### 4.2 安装与运行

```bash
# 克隆项目
git clone https://github.com/your-username/llm-news-daily.git
cd llm-news-daily

# 安装依赖
pip install -r requirements.txt

# 启动服务（首次运行自动创建数据库）
python -m uvicorn src.web_app:app --reload --host 0.0.0.0 --port 8080
```

浏览器访问 `http://localhost:8080`

### 4.3 配置 LLM

首次使用前，通过页面右上角「模型配置」设置 LLM 服务：

| 参数 | 说明 | 示例 |
|------|------|------|
| Provider | 服务商名称 | deepseek |
| API Key | API 密钥 | sk-xxx |
| API URL | API 地址 | https://api.deepseek.com/v1 |
| Model Name | 模型名称 | deepseek-chat |

**推荐配置**

| 供应商 | API URL | Model |
|--------|---------|-------|
| DeepSeek（推荐） | https://api.deepseek.com/v1 | deepseek-chat |
| 通义千问 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |
| 智谱 GLM | https://open.bigmodel.cn/api/paas/v4 | glm-4 |
| 本地 Ollama | http://localhost:11434/v1 | llama3 |

## 6 使用流程

1. 打开浏览器访问 `localhost:8080`
2. 配置 LLM 模型（首次使用）
3. 输入关键词，点击「立即搜索」
4. 查看 Top 10 结果（自动翻译 + AI 摘要）
5. 对感兴趣的新闻点 👍，不感兴趣的点 👎
6. 可选：输入文字反馈补充偏好说明
7. 再次搜索 → 排序已根据你的反馈优化
8. 勾选新闻 → 导出 Markdown 日报
